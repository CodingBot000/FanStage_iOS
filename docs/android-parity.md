# Android 기능 대조

기준: Android 저장소 현행 코드의 `MainActivity`, `feature` 화면 및 데이터 계약. 이 문서는 화면 단위 대조이며 완전한 동등성 검증을 뜻하지 않는다.

| 영역 | iOS에서 확인한 범위 | 남은 차이 |
|---|---|---|
| Discover | LIVE 진입, Replay, 아티스트 커뮤니티 진입 | Android 추천·벤치마크 카드, 로딩·오류 화면과 세부 레이아웃은 미이관 |
| Community | 전체 및 아티스트 게시물, 좋아요·댓글 | Android 아티스트 상세 탭과 로딩·빈 상태, 디자인 세부는 미이관 |
| Media | LIVE·Replay 진입 및 필터 | Debug 로컬 영상 일곱 항목과 Android 데이터·상태 표시 미이관 |
| Messages | 대화 목록, 최신 메시지, 입력 | 읽지 않음 상태·표시와 Android 상세 배치는 미이관 |
| LIVE·Replay | 영상, 세로 전체 화면, 속도·자막·비트레이트, Fake 채팅 | 기본 합성 HLS 대신 변환 MP4 사용, Android의 세부 화질 선택·로컬 MP4 매핑 및 플레이어 상태 UI 미이관 |
| 실제 채팅 | 기존 서버 WebSocket·HTTP, 순서 병합, 누락 보충, 동일 ID 재전송, 룸별 메모리 보존 | 앱 종료 후 미확정 상태는 보존하지 않으며 ACK 유실 후 동일 ID 재시도와 재연결은 격리 서버에서 검증. 이벤트 역순·지연 HTTP·장시간 누수는 iOS 실제 장애 주입 미검증 |
| 접근성·언어 | 일부 접근성 라벨과 한국어/영어 문자열 | VoiceOver·Dynamic Type 전체 검증과 가상 데이터 문구의 현지화 미완료 |

검증 환경과 명령은 [README](../README.md)를 참고한다. 회전 대응은 사용자 결정에 따라 범위에서 제외하며 세로 방향을 유지한다.
